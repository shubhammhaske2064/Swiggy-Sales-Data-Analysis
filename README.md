# Swiggy Sales Analysis Dashboard (Excel)

## 📌 Project Overview

This project analyzes Swiggy food order data using Microsoft Excel to uncover sales trends, customer preferences, restaurant performance, and city-wise business insights. The project demonstrates data cleaning, analysis, and dashboard creation using Excel's analytical capabilities.

The goal is to transform raw order data into meaningful business insights through interactive visualizations and KPI tracking.

---

## 📊 Dataset Information

The dataset contains approximately **197,430 food orders** with information such as:

- State
- City
- Order Date
- Month
- Day
- Quarter
- Restaurant Name
- Location
- Food Category
- Dish Name
- Food Type
- Price (INR)
- Rating
- Rating Count

## 🔄 Project Workflow

### 1. Data Collection
Imported Swiggy sales dataset into Excel.

### 2. Data Cleaning
- Checked for missing values
- Standardized data formats
- Verified data consistency

### 3. Data Analysis
Performed analysis on:
- Total Sales
- Total Orders
- City-wise Sales
- Category-wise Performance
- Restaurant Performance
- Customer Ratings
- Monthly Trends

### 4. Dashboard Creation
Created an interactive Excel dashboard using:
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Metrics
